## Requested outcomes versus implemented scope

### 1. End-to-end assembly mate edits and motion

**Existing Sprint 14 capabilities retained:** persistent rigid mates, revolute/prismatic articulated joint graphs and rebind, single-joint axis/limit/pose editing, multi-drive coordinates, sampled motion preview and CSV, nominal solid interference and bounded translational swept-AABB checks. Sprint 15 does not claim continuous narrow-phase collision proof for arbitrary rotating solids.

**New:** `SceneDocument::previewLiveArticulatedJointDefinitionBatch` and `replaceLiveArticulatedJointDefinitionBatch` stage *several* saved mate-frame or limit edits in one graph solve, regenerate all affected OCCT B-reps as one transaction, optionally require exact nominal fit, and commit once with undo/redo. A rejected index, edge change, invalid geometry or strict-fit failure leaves the scene and outputs untouched. The Qt **Assembly → Edit ALL saved articulated mate frame offsets** command exposes per-joint zero-frame XYZ editing and a confirmation preview. Other joint parameters remain editable through the existing detailed single-joint UI. Native tests in `tests/articulated_assembly_scene_v170_tests.cpp` now exercise two edits, invalid batch rollback, preview invariants, one-step undo/redo and save/reopen.

### 2. Generalized associative drawing regeneration

**Existing Sprint 14 capabilities retained:** individual saved-sheet SVG regeneration with human preview before re-acknowledging source revision; batch unissued SVG/PDF previews; atomic multi-sheet witnessed-edge reviews and recovery register.

**New:** `SceneDocument::buildSavedDrawingSvgBatch` regenerates **1–12 existing saved sheets** from current source B-reps, annotations, BOM, drawing metadata and orthographic/section/detail views, without modifying the scene. It refuses missing or duplicate sources, stale edge-dimension or GD&T revisions, missing witnessed geometry, invalid SVGs and an oversized output set. `exportSavedDrawingSvgBatch` publishes a newly named directory of SVGs plus SHA256 index after all renders succeed. It will never overwrite an existing directory or acknowledge an issued source revision. The Qt **File → Regenerate all saved drawings (strict atomic SVG batch)** command exposes this independent fail-closed path. The existing optional PDF batch command remains. `tests/document_audit_tests.cpp` exercises two source-linked sheets, source changes, duplicate rejection, re-render, whole-directory publication and non-overwrite. Actual geometry, annotations and PDFs require visual checking before issue.

### 3. Geometry-based folded sheet refold audit

**Existing Sprint 14 capabilities retained:** folded solids generated by radiused, faceted 2-D section extrusion; linked flat SVG/DXF/CSV development and geometric overlap preflight; sheet production packages and independent handoff verifiers.

**New:** `src/core/RefoldGeometryAudit.h` independently integrates neutral centerline lengths for signed mixed-direction bends, measures the actual folded closed polygon area, validates 2-D contour simplicity and checks area conservation (0.5% bound against the mid-thickness reference). This runs within `SheetMetal::buildFoldedSheetOutline` so rejected edits never reach OCCT. `SceneDocument::auditFoldedSheetRefoldGeometry` regenerates the actual stored folded solid and compares **stored OCCT volume, rebuilt OCCT volume and independent faceted section volume**. The Qt **Inspect → Audit stored folded refold geometry and OCCT volume** command offers an unissued CSV. Native tests in `tests/cadcore_tests.cpp --folded-sheet-metal` check one-bend and three reversing bends, result preservation on failure, and persisted-solid volume. A separate portable randomized/deterministic stress module runs 50,014 checks.

**Scope limitation:** This validates the currently supported **linear, constant-width multi-flange folded section**; it does not reverse-engineer arbitrary imported 3-D sheet-metal B-reps, resolve multi-plane corner intersections, model springback, generate production-grade relief tooling, or establish global collision-free sweep of a forming process. These features remain outstanding.
