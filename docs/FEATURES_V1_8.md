# v1.8 Precision & Utility Components

v1.8 adds 70 dimensioned commands in **Create > Precision & Utility Components** and the Create ribbon group. Each command builds one undoable direct solid from editable dialog dimensions. The named parts use nine common solid families; geometry is an illustrative starting model, not a manufacturing-ready design.

## Model limits

These commands create checked direct solids. They do not create editable feature timelines, validated medical or structural parts, certified pressure equipment, or production-ready gearing. Internal details, fasteners, threads, seals, and fit tolerances are not fully represented.
