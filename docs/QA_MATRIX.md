## Scope status for the current continuation

- **Parametric foundation:** linked dimensions can change drivers directly in one validated transaction. The rectangle/extrusion/hole/pattern/all-edge-chamfer chain supports named chamfer distance, suppression, and rebuild of optional downstream operations. A 2D point/segment solver drives trapezoid, triangle, and vertex-defined polygon extrusions; their sketch definitions persist and dimensions/anchors rebuild through an Edit dialog after reopening. The UI cannot add non-fixed sketch constraints or arcs/splines; arbitrary feature reorder/insert and a general feature dependency graph remain unsupported.
- **Parametric continuation:** one editable blind-hole operation has a named `hole_depth`, links, suppression, rebuild, persistence, and validation. Its focused test passes 31 assertions. This is an incremental feature-history operation; it does not add a general sketch solver.
- **Assemblies:** persistent occurrences, fixed placement, undoable linear and world-Z circular patterns (up to 100 total occurrences), rigid/revolute/prismatic joints, motion tracks, explicit geometry plus shared BOM/material definition synchronization, and derived BOM aggregation are covered. Patterns reject jointed subassemblies and are static placements, not live associative features. Closed-loop solving and general 6-DOF placement remain outside the implemented scope.
- **Drawings:** separate geometry and BOM/material source fingerprints, explicit refresh, stale/missing-source handling, legacy-token migration, and persistent annotation identities are regression-covered. SVG/PDF output remains a snapshot and formal ISO/ASME compliance is not implemented.
- **Sheet metal:** one-bend SVG and multi-bend DXF support user-selected bend data, reliefs, and opt-in shop limits. Folded solids preserve editable bend inputs, support an undoable rebuild, and export a current-definition blank DXF; direct edits make the definition stale/read-only. DXF files are point-in-time snapshots without automatic refresh or reliefs. The geometry uses sampled bend facets; exact analytic faces, springback, and tool-specific compensation remain incomplete.
- **Document revision history:** immutable local checkpoints support name, compare, integrity check, tags, retention pruning, optional save checkpoints, and restore to a separate file. Detailed comparisons include JSON field paths and old/new values. Checkpoints do not provide a general editable or replayable feature timeline, dependency rebuild, or branches.
- **Surfaces and meshes:** scenes persist face/shell surface bodies; the UI exposes loft, selected-edge extrusion/revolution, selected-face offset/extension, solid-guided trim and face split, open-shell sewing, thickening, and stitching into solids. Shell sewing requires connected surfaces and verifies face retention; solid-guided splitting validates area conservation and saves fragments separately. Trim can keep inside or outside regions and create multiple separate surface bodies. Planar face thickening uses direct extrusion; other surfaces use kernel offset thickening. Mesh import supports configurable weld tolerance, optional convex planar hole caps, and preservation of open manifold OBJ/STL as faceted surface bodies. Live UI verification, native triangle editing, arbitrary free-form split/merge, arbitrary boundary repair, and editable surface history remain incomplete.

Build and test locally with the project's Windows build script or the checked-in CMake/vcpkg setup. Do not treat automated core coverage as a claim of full Fusion 360 parity or ISO/ASME certification.
