## 75%: integrate existing workflows, rather than add new isolated calculations

1. **Signed CAD → independent measurement → dimensional review.** `tools/review_measured_holes.py` reads a verified UNISSUED manufacturing package generated by the existing native handoff writer (v2), then consumes a completed copy of `hole_position_inspection_TEMPLATE.csv` stored *outside* the signed package. Only `MEASURED` rows are allowed. It requires every CAD hole exactly once with the same body identity, hole number, geometry revision and **byte-for-byte unchanged nominal coordinates and diameter**. It rejects stale or tampered packages, edited nominal geometry, duplicate/unknown/missing holes, nonfinite values, extra approval columns, invalid material conditions, size bounds and inconsistent projected axes. It evaluates RFS/MMC diametral position, bonus, size and optional pin clearance using the same defined arithmetic as the existing native `HolePositionInspection.h`; results are explicitly **review required**. Report includes SHA-256 of source manifest and independent measurement file, individual findings and CSV/JSON outputs. It neither automatically reads CMM machines nor establishes a measurement datum or accredited calibration.
2. **Unissued drawing-to-manufacturing revision reconciliation.** `tools/reconcile_drawing_handoff.py` independently verifies the signed native manufacturing handoff and the unissued SVG/PDF batch checksums before checking drawing owner IDs, uniqueness of sheet owners/drawing numbers, saved model revision tokens and missing-sheets inventory. A drawing with an aggregate/multi-body source token may not equal the owner-body token: this is flagged **for investigation**, not automatically called stale. Output never claims a geometry release, drawing approval or verification of all GD&T. Neither signed input folder is changed.
3. **One integrated engineering punch list.** `tools/engineering_readiness_workflow.py` joins the existing procurement, document-audit and feature-inspection requirements with the two results above, retaining explicit actions for absent measurements, absent drawings, missing or inconsistent records, failed entered limits, and mandatory human engineering/inspection release. It produces safe, external JSON/CSV action registers and never approves fabrication. Source verification is repeated by the called services.

## 20%: reliability and performance

4. **Stable swept collision evidence despite assembly occurrence order.** `src/core/MotionSweptClearance.h` now provides `proximity::OrderInvariantSweptTracker`, a stable-ID adapter over the existing transaction-safe, increasing-time swept-AABB solver. `SceneDocument.cpp` uses it in articulated envelope generation alongside `OrderInvariantTracker` for same-pose comparisons. Duplicate IDs, missing IDs, changing box extents, repeated timestamps or nonfinite input reject without changing the previous sweep result. This is still conservative AABB translation **broad phase**, not exact B-rep narrow phase or rotating-body certification.
5. Integration in existing `tests/articulated_assembly_v170_tests.cpp` CTest target and a new 2,410-assertion C++ suite `tests/order_invariant_swept_portable_tests.cpp`; no new native CTest names. Fixed an obsolete Sprint 5 structural assertion to expect the new safely ordered tracker rather than the old directly instantiated type. Source/package audit, 130 registration gate and failure diagnostics remain active.
6. `RUN_SPRINT11_WINDOWS_TARGETED_BUILD.ps1` checks source and integration contracts, then compiles `cadcore`, workshop/document audit targets and two articulated assembly test binaries before running four relevant native CTests. Optional `-FullAudit` runs full MSVC app, all 130 CTests and full Python tests. The source diagnostic expected-test-count was updated to **952**.

## Actual shop-floor review workflow (sample commands, fresh PowerShell)

**First export** an UNISSUED manufacturing handoff from the latest saved CAD model and optionally unissued drawings from CADWorkbench. Do **not** edit the signed handoff folder. Make a copy of `hole_position_inspection_TEMPLATE.csv` outside the folder (for example `Downloads\ShopReview\measurements.csv`). The inspector must enter all ten measured/tolerance numeric fields (use `0` when there is no pin), set `material_condition` to exactly `RFS` or `MMC`, and set `inspection_status` to `MEASURED`. Never modify the nominal coordinates, IDs, source token or hole number.

From the extracted Sprint 11 source folder:

```powershell
$python = 'py'
$handoff = "$env:USERPROFILE\Downloads\CADWorkbench_Engineering_Handoff_EXAMPLE"
$measured = "$env:USERPROFILE\Downloads\ShopReview\measurements.csv"
$drawings = "$env:USERPROFILE\Downloads\CADWorkbench_Unissued_Drawings_EXAMPLE"
# Replace the two EXAMPLE folder names with actual exported folders.
& $python -3 .\tools\verify_manufacturing_handoff.py $handoff
& $python -3 .\tools\review_measured_holes.py $handoff $measured --json "$env:USERPROFILE\Downloads\ShopReview\inspection_review.json" --csv "$env:USERPROFILE\Downloads\ShopReview\inspection_review.csv"
& $python -3 .\tools\reconcile_drawing_handoff.py $handoff $drawings --json "$env:USERPROFILE\Downloads\ShopReview\drawing_reconciliation.json"
& $python -3 .\tools\engineering_readiness_workflow.py $handoff --measured-csv $measured --drawings $drawings --json "$env:USERPROFILE\Downloads\ShopReview\open_actions.json" --csv "$env:USERPROFILE\Downloads\ShopReview\open_actions.csv"
```

Each output must be a new path outside the signed input folders. The tool rejects existing output paths to protect prior evidence. The sample reports are **independent evidence pending professional review**, not a manufacturing authorization.
